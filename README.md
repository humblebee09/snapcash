# Next.js Point of Sale (POS) App

A modern, **Point of Sale (POS)** web application built with **Next.js**, **ShadCN UI**, and **TailwindCSS**. Designed to streamline transaction processes, manage tables, menus.

## Features

- Table & Order Management
- Menu CRUD
- Status Meja (Available, Occupied, Reserved)
- Customer Input for Reserved/Occupied Tables
- Responsive UI
- Built with TypeScript & Prettier

---

## Tech Stack

- [Next.js 15 (App Router)](https://nextjs.org/)
- [ShadCN UI](https://ui.shadcn.dev/)
- [TailwindCSS](https://tailwindcss.com/)
- [TypeScript](https://www.typescriptlang.org/)

---

## Installation

```bash
npm install / npm install --force
```

## 🚀 Run

```bash
npm run dev
```
